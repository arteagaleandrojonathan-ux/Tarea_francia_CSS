# API PRODUCTOS - tiendaperu

## Tarea 09 · Inventario de productos

La maqueta presenta una barra de navegación y una tabla con datos de ejemplo de la tienda. Cada fila incluye los botones **Editar** y **Eliminar**, identificados con un lápiz y una papelera.

### Cómo abrir la maqueta

1. Abre [public/index.html](public/index.html) 
en un navegador actualizado con conexión a internet. 

2. Pulsa **Nuevo producto** para abrir el diálogo **Registrar producto**.

3. Prueba los campos **Marca**, **Descripción**, **Precio (S/)** y **Stock**. Pulsa **Cancelar** para cerrar el diálogo.

La maqueta funciona directamente desde el HTML. **Guardar**, **Editar** y **Eliminar** son controles visuales
